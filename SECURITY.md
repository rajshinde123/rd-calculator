# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security issue, please do not open a public issue.
Instead, report the issue privately by contacting [@rajshinde123](https://github.com/rajshinde123) or using GitHub's Private Vulnerability Reporting feature under the repository's Security tab.

We will review reports promptly and take necessary steps to address verified security concerns.
